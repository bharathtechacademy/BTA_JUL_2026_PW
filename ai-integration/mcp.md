# What is MCP ?

MCP is nothing but Model Context Protocol, and this is going to allow a model to connect with the tools available on the computer. By taking instructions from the AI model, it is going to connect to the tool, and it is going to complete the task for us. 

For each and every tool, a specific MCP server will be created. According to the instructions added in the MCP server by the people who created it, now it is going to take the instructions from the user and work according to that.
